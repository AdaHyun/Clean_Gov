# 1.狂犬病简介

• 狂犬病是由狂犬病病毒引起的动物源性传染病 (人兽共患病)狂犬病导致急性进行性脑炎一旦出现症状,几乎全部死亡  
犬是狂犬病的主要宿主和传播动物通过咬伤或抓痕经唾液传给人

# 99% 的人狂犬病病例源于犬

被犬伤后的处置 （暴露后预防）是预防狂犬病的唯一有效手段伤口处理 + 免疫球蛋白 + 疫苗“公平全民及时可及”

犬接种疫苗是最具成本效益的方法阻断传播,是消除狂犬病的根本

# 狂犬病

狂犬病病毒（至少有 14 种）感染引起的急性脑炎临床上人狂犬病分为狂躁型或麻痹型一旦出现病临床症状,几乎全部死亡  
• 潜伏期 多为 1\~3 个月,也有 >1年的记载暴露后,高度嗜神经性的狂犬病病毒在肌肉组织中复制进入周围神经,经周围神经系统扩散到脊髓并上行至脑部到达脑部后,病毒迅速复制和播散经神经系统播散到许多不同的组织,包括唾液腺  
• 临床狂犬病存活极罕见如无重症监护,通常入院后 2\~3 天内死亡

# 狂犬病重要事实

狂犬病是一种疫苗可预防的病毒性疾病  
全球有该病国家和地区 >150  
高达 99% 人狂犬病死亡病例源于犬  
小部分是通过野生动物传播的（如狐狸、狼、豺狼、蝙蝠、浣熊、臭鼬或猫鼬）  
犬接种疫苗和防止犬咬伤,可阻断传播  
每年导致数万人(59000)死亡,主要在亚洲和非洲  
被疑患狂犬病动物咬伤者中, <15 岁儿童占 40%  
接触疑患狂犬病动物后  
立即用肥皂和水彻底清洗伤口极为重要,可挽救生命  
WHO牵头组织 ［联合国粮食及农业组织（FAO）、世界动物卫生组织（OIE）和全球狂犬病控制联盟(GARC)  
成立“联合抗击狂犬病”全球合作 ―United Against Rabies‖  
推动实现“到 2030 年人类狂犬病零死亡”

# 狂犬病

狂犬病是由狂犬病病毒感染  
引起的一种动物源性传染病  
狂犬病病毒主要通过  
破损的皮肤或粘膜侵入人体  
临床大多表现为特异性  
恐风、恐水、咽肌痉挛、 进行性瘫痪等  
近年来,狂犬病报告死亡数  
一直位居我国法定报告传染病前列  
给人民群众生命健康带来严重威胁

# 狂犬病在自然界的储存宿主动物

# 包括食肉目动物和翼手目动物

狐、狼、豺、鼬獾、貉、臭鼬、浣熊、猫鼬和蝙蝠等  
也是狂犬病的自然储存宿主  
均可感染狂犬病病毒成为传染源  
进而感染猪、牛、羊和马等家畜

狂犬病易感动物主要包括犬科、猫科及翼手目动物禽类、鱼类、昆虫、蜥蛎、龟和蛇等不感染和传播狂犬病病毒全球范围内, 99% 的人狂犬病是由犬引起
